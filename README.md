# ⭐ Projeto em destaque

## 📚 Sistema de Gestão de Alunos e Aulas

Sistema Web desenvolvido para gerenciamento de professores, alunos, aulas e controle financeiro.

### Funcionalidades

- 🔐 Login e autenticação de professores
- 👨‍🏫 Cadastro e gerenciamento de professores
- 👨‍🎓 Cadastro e gerenciamento de alunos
- 📅 Controle dos dias e horários de estudo
- ✅ Registro de presença e faltas
- 💰 Controle do valor por aula
- 🧮 Cálculo das aulas realizadas
- 📊 Relatórios de presença e faltas
- 💵 Apoio ao controle financeiro e cobrança dos alunos
- 🔒 Controle de acesso por usuário
- 📱 Interface adaptada para diferentes dispositivos

### Tecnologias

`PHP` `MySQL` `JavaScript` `HTML5` `CSS3`

O projeto foi desenvolvido de forma completa, desde a estrutura do banco de dados até o desenvolvimento do front-end, back-end, autenticação, regras de negócio e relatórios.
